DATA & PRIVASI

Privacy Policy

Halaman ini menjelaskan data yang diproses ReactionSw untuk akun, preferensi bot, pairing WhatsApp, dan log aktivitas.

Terakhir diperbarui: 8 November 2026

1. Data yang diproses

  • Data akun: nama tampilan, username, alamat email, avatar profil, waktu pembuatan akun, dan peran akun. Kata sandi disimpan sebagai hash ber-salt; kata sandi asli tidak disimpan dalam bentuk teks biasa.
  • Avatar profil: kamu dapat memilih avatar bawaan yang disimpan di aset web atau mengunggah gambar sendiri. Gambar unggahan dipotong persegi dan dikonversi di browser menjadi WebP 512 × 512, dibatasi maksimal 1 MB, lalu disimpan di folder akun masing-masing pada DATA_AKUN. Avatar unggahan hanya disajikan kembali kepada akun yang sedang masuk.
  • Sesi dan aktivitas panel: cookie autentikasi bernama readsw_session, masa berlaku sesi, serta heartbeat saat dashboard terbuka untuk menandai aktivitas panel terbaru. Status “aktif di panel” berarti heartbeat terlihat dalam 75 detik terakhir; ini bukan status online WhatsApp.
  • Statistik pengunjung realtime: footer menampilkan jumlah akun yang sedang aktif di panel sebagai “Online” dan jumlah browser yang membuka halaman tanpa login sebagai “Stalker”. Pengunjung anonim memakai cookie sementara readsw_visitor; sistem menyimpan waktu kunjungan, jumlah hit, serta kategori/perangkat, sistem operasi, model yang terbaca, dan browser dari User-Agent. IP mentah tidak disimpan pada data stalker, dan hitungan tidak dapat memastikan identitas orang atau mendeteksi perangkat secara sempurna.
  • Preferensi bot: mode pilihan, rentang delay, toggle reaksi, dan daftar emoji yang disimpan pada profil akun.
  • Pairing WhatsApp: nomor yang kamu masukkan dipakai untuk meminta pairing code. Kode hanya berada di memori sementara paling lama tiga menit dan tidak dimasukkan ke log. Setelah perangkat berhasil ditautkan, file auth Baileys di penyimpanan server dapat memuat identitas WhatsApp, kredensial, serta kunci sesi yang diperlukan agar koneksi dapat dipulihkan.
  • Log aktivitas: jenis event, waktu, mode, tipe media/story, nama profil jika tersedia, nomor yang disamarkan, ID story yang dipendekkan, hasil tanda dibaca/reaksi, dan delay. Aplikasi tidak mengunduh atau menyimpan foto, video, maupun isi story.
  • Informasi yang terlihat oleh admin: halaman admin menampilkan username, nama tampilan, email, peran/verifikasi, waktu pendaftaran, aktivitas panel terbaru, status koneksi sesi WhatsApp dan status worker. Nomor WhatsApp—jika tersedia—hanya ditampilkan tersamarkan. Daftar diperbarui berkala; halaman admin tidak membuka pairing code, kredensial, atau log privat akun.

2. Tujuan penggunaan

Data digunakan untuk membuat dan mengamankan akun, menyimpan preferensi, menampilkan status pairing/worker, menyediakan log privat bagi akun yang sedang masuk, serta memberikan ringkasan akun dan aktivitas panel kepada admin. Status koneksi menunjukkan keadaan koneksi teknis sesi WhatsApp; aplikasi tidak mengetahui atau menjanjikan apakah orang sedang aktif menggunakan WhatsApp. Saat Read Only berjalan, panel dapat mengirim tanda dibaca. Saat reaksi otomatis diaktifkan pada mode Read Only + ReadSW, panel dapat mengirim reaksi emoji pilihan. Tindakan tersebut dikirim melalui koneksi WhatsApp dan dapat terlihat oleh pemilik story.

3. Penyimpanan dan keamanan

Data aplikasi disimpan pada penyimpanan server yang dikonfigurasi operator, termasuk file akun dan log serta folder auth WhatsApp per akun. Direktori dan file diberi pembatasan izin akses di sistem berkas, tetapi penyimpanan auth saat ini tidak dienkripsi at-rest. Operator server atau pihak yang memperoleh akses ke sistem berkas mungkin dapat mengakses data tersebut. Jangan gunakan deployment yang tidak menyediakan penyimpanan persisten dan kontrol akses yang layak untuk akun utama.

Log yang terlihat di panel dibatasi hingga 100 entri terbaru per akun. Penyimpanan aplikasi tidak menjanjikan penghapusan otomatis semua log lama; pengelolaan retensi bergantung pada operator dan konfigurasi server.

4. Pihak ketiga

Pairing dan aktivitas bot berkomunikasi dengan layanan WhatsApp melalui library komunitas Baileys yang tidak berafiliasi atau disahkan WhatsApp. Penyedia hosting/infrastruktur yang menjalankan panel dapat memproses permintaan jaringan dan mengelola server tempat data disimpan. Penggunaan WhatsApp juga tunduk pada ketentuan dan kebijakan WhatsApp.

5. Retensi, penghapusan, dan permintaan privasi

Akun, preferensi, dan log disimpan pada server sampai operator menghapus atau membersihkannya. Panel saat ini belum menyediakan tombol hapus akun secara mandiri. Tombol hapus sesi WhatsApp hanya menghapus kredensial sesi WhatsApp dari server; tindakan itu tidak menghapus akun panel, preferensi, atau seluruh log.

Untuk meminta akses, koreksi, atau penghapusan data, hubungi pengelola melalui kanal WhatsApp support atau Telegram support. Sertakan username akun dan jelaskan permintaanmu. Jangan kirim kata sandi, pairing code, atau file kredensial WhatsApp melalui chat.

6. Pembaruan kebijakan

Kebijakan ini dapat diperbarui ketika fitur atau cara penyimpanan berubah. Versi terbaru akan ditampilkan pada halaman ini. Jika ada pertanyaan tentang data dan privasi, gunakan kanal kontak di atas.

Catatan keamananPairing code adalah kredensial masuk sementara. Masukkan sendiri di WhatsApp dan jangan membagikannya kepada siapa pun.
