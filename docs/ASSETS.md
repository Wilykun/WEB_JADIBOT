# Aset antarmuka

Dashboard memakai logo sederhana berbasis CSS, ikon teks, dan gradient CSS buatan sendiri. `public/favicon.svg` adalah ilustrasi favicon anime 2D yang digambar khusus untuk ReadSW Console, disederhanakan agar terbaca pada tab browser. Referensi gaya: [konard/anime-avatar](https://github.com/konard/anime-avatar), yang merilis kode 2D SVG di bawah Unlicense. Favicon proyek ini merupakan gambar SVG khusus, bukan karakter berhak cipta atau file yang disalin dari repo tersebut.
